# Stories

Post-mortems and win stories from operating loops on this repo. One file per story:
`YYYY-MM-DD-short-title.md`.

Template:
- Loop / level / date
- Symptom
- Root cause
- What mitigated it (or didn't)
- Constraint/gate/skill change that followed

Failure stories are first-class — if a loop shipped something wrong and there is no
story here, the loop learned nothing.
